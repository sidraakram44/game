# YourSite — Static Starter

A clean, responsive, accessible static website starter built with HTML, CSS, and a touch of vanilla JS.

## Run locally

- Option 1: Open `index.html` directly in your browser.
- Option 2: Serve with a local web server (recommended for consistent behavior):

```bash
python3 -m http.server 8000 --directory /workspace
```

Then open `http://localhost:8000`.

## Customize

- Edit copy and sections in `index.html`.
- Tweak colors, spacing, and components in `styles.css`.
- Add interactivity in `script.js`.

## Deploy

- Upload these files to any static host (e.g., GitHub Pages, Netlify, Vercel, Cloudflare Pages, S3).
- No build step required.
